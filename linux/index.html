Learning Step 0 — Linuxって何をしているの？

Web/APIへアクセスすると、いきなりnginxコマンドが登場するわけではありません。名前解決 → 通信 → Port → Process → Application → Logという経路があります。まずこの一本を掴みます。

① User / App要求を送る
② DNS / IP宛先を決める
③ Port / Firewall通信が届く
④ Processnginx等が受ける
⑤ Log / Result証拠と結果を確認
ready> ①から順に押してみよう。
