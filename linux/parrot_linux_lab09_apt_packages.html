🌐 Repository / Sources — Packageはどこから来る？

RepositoryPackageとmetadataを配布するServer。
SourcesどのRepositoryを参照するかの設定。
SignatureRelease metadataが信頼できる配布元か検証。
$ grep -R "^[^#].*deb" /etc/apt/sources.list /etc/apt/sources.list.d/ 2>/dev/null # 学習用イメージ: deb https://mirror.example/debian stable main
apt updateは何をdownloadする？
$ sudo apt update Get:1 ... InRelease Get:2 ... Packages Get:3 ... DEP-11 Metadata Fetched package indexes... # .deb本体を全部installするわけではない # 「何が何versionで存在するか」のcatalog更新

Holdの意味

🧩 Dependency — 1 Packageだけで動いているとは限らない

nginx → nginx-common (= 1.26.2-2)
nginx → libc6 (>= 2.36)
nginx → libssl3 (>= 3.x)
$ apt-cache depends nginx nginx Depends: nginx-common Depends: libc6 Depends: libssl3 # apt: # Dependencyも含めて解決 # dpkg -i: # .debを展開/設定するが # Repositoryから依存関係を自動解決する役ではない

🔒 APT Lock — 同時にPackage DBを書き換えない

現在 lock free。
よくあるNG: lock Fileを見つけた ↓ 考えず rm /var/lib/dpkg/lock-frontend これは避ける まず: ps / systemctl ↓ apt/dpkgが本当に動作中？ ↓ 正常処理なら待つ ↓ 異常終了なら状態を確認して復旧 Package DB破損を増やさない

🔏 Repository署名 — 「downloadできる」だけでは信頼しない

Release metadata signature: VALID
$ sudo apt update Hit:1 ... InRelease Reading package lists... Done # Repository metadataを # trusted keyring / signed-by等で検証 # 署名Errorを # --allow-unauthenticated等で # 雑に無視しない

⬆️ update / upgrade / full-upgrade — 似ているけど役割が違う

apt updateIndex更新。Installed packageはそのまま。
apt upgrade可能な範囲でInstalled packageを新Versionへ。
apt full-upgrade必要ならPackage削除も含め依存関係を解決して更新。
$ apt list --upgradable nginx/stable 1.26.2-2 amd64 [upgradable from: 1.24.0-1] openssl/stable ... [upgradable]
更新後に確認すること
Package update成功 ≠ 業務影響ゼロ 確認: - Service active? - Config compatibility? - Port listen? - Application smoke test? - Library更新を既存Processが読み直した? - Restart / reboot必要? - Rollback手段ある? Maintenance設計まで含めてUpdate

🧩 コマンドを分解する

コマンドを押すと意味を分解します。
Package障害の一次切り分け: 1. apt update Repository / DNS / Signature 2. apt-cache policy Installed / Candidate / Source 3. apt-mark showhold holdされてない？ 4. dpkg --audit / dpkg -l unpacked / unconfigured? 5. ps / lock 別aptが動いてる？ 6. df -h /var download・unpack容量ある？ 7. Service確認 Update後の実動作まで見る
