# Oracle / OCI reference notes

The curriculum uses Oracle Database and OCI as product-context examples, not as regulatory or production runbooks.

## Oracle Database profile

Conceptual evidence examples used in the learning UI:

- Session / performance context: Oracle dynamic performance `V$` views
- Lock context: `V$LOCK` together with session context such as `V$SESSION`
- Data dictionary: Oracle data dictionary / dynamic performance views

## OCI provider profile

Conceptual service map used in Cloud Fundamentals:

- Virtual network: VCN
- Compute: OCI Compute
- Database: Base Database / Exadata Database Service / Autonomous AI Database depending workload and operating model
- Identity: OCI IAM
- Key / secret control: OCI Vault
- Observability: OCI Monitoring
- Control-plane audit: OCI Audit
- Hybrid private connectivity: FastConnect / Site-to-Site VPN

Product names and capabilities evolve. Treat the profile as a learning translation layer and confirm current Oracle documentation before production design.
