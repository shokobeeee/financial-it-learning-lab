# Investigation Game PR Notes

This branch changes Financial War Room from a prescribed linear checklist UI into an investigation game.

Review focus:

- Preview must not reveal a prescribed answer order.
- Evidence can be investigated in free order after impact declaration.
- Evidence Board must show facts without automatically interpreting them.
- Hypothesis Board states are learner-controlled: investigating / hot / ruled out.
- Cause declaration remains gated by Evidence Diversity.
- Recovery / Verification / Communication open after cause declaration.
- Existing 85/85/85 tri-role scoring and result keys remain unchanged.
- Evidence layer metadata is explicit in the investigation UI and consumed by the v16 gate.
